# Changelog

All notable changes to this package are documented in this file.

## [1.0.0] - 2026-08-16

### Added

- Initial release: `ScreenService` with `OpenScreenAsync`, loading screens as additive scenes and driving a stack of opened screens.
- `UIScreen` abstract component and `UIScreenData` ScriptableObject for authoring screens.
- `IUIScreen`, `IScreenService` abstractions and `ScreenType` enum.
